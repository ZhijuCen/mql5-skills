# Matrix Write and Read Methods

Methods for writing matrices to files and reading matrices from files.

| Function | Action |
| --- | --- |
| Write | Writes a matrix to a file according to the selected storage method |
| Read | Reads from a file a matrix written by the Write method |
| WriteBin | Writes a matrix to a file according to its size and type |
| ReadBin | Reads from a file a matrix written by the WriteBin method |
| WriteCSV | Writes a matrix or vector to a CSV file according to its size and type |
| ReadCSV | Reads from a CSV file a matrix or vector written by the WriteCSV method |
